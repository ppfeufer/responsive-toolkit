Responsive Toolkit source test

This page opens one isolated preview for each supported framework plus a custom-breakpoint preview. Each frame loads the current responsive-toolkit.js source and exercises the matching breakpoint rules inline, so you can resize the browser and verify the active alias for every setup.

Default breakpoints

Uses the toolkit default behavior and the inline responsive-toolkit.css rules.

Bootstrap 3

Exercises the Bootstrap 3 visibility classes supported by viewport.use('Bootstrap3').

Bootstrap 4

Exercises the Bootstrap 4 visibility classes supported by viewport.use('Bootstrap4').

Bootstrap 5

Exercises the Bootstrap 5 visibility classes supported by viewport.use('Bootstrap5').

Custom breakpoints

Uses inline custom breakpoint CSS and a custom breakpoint map via viewport.use().

Tip: resize the browser, then open the DevTools console inside any frame to watch the current breakpoint reported by viewport.current().
